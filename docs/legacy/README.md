# Legacy Records

These v1 files preserve the previous topology description and its source
records. They were derived from the historical `architecture-v1.drawio` and
were not verified against the live machines. Use them as historical leads only;
they do not define current state or desired architecture.

The editable draw.io file is now a readability redraw of that historical
report. It preserves the reported relationships but does not add verification;
the SVG is retained as the older flattened render and may not match the redraw's
layout.

- `state-v1.md` — previous state document, including proposed guest roles.
- `architecture-v1.drawio` — editable readability redraw of the historical
  topology.
- `architecture-v1.svg` — older preserved flattened render.
- `nodes-v1.yaml`, `network-v1.yaml`, and `storage-v1.yaml` — previous
  inventory records.
