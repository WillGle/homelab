# Legacy Records

These v1 files preserve the previous topology description and its source
records. They were derived from `architecture-v1.drawio` and were not verified
against the live machines. Use them as historical leads only; they do not
define current state or desired architecture.

- `state-v1.md` — previous state document, including proposed guest roles.
- `architecture-v1.drawio` and `architecture-v1.svg` — preserved topology
  diagram and render.
- `nodes-v1.yaml`, `network-v1.yaml`, and `storage-v1.yaml` — previous
  inventory records.
